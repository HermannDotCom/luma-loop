# Éléments de fiche store — Luma Loop

## Positionnement

Luma Loop est un jeu de réflexe visuel à une touche. Il est conçu pour être compréhensible sans tutoriel long : le joueur touche lorsque la lumière menthe rejoint la porte ambre. Les parties sont rapides et les scores sont enregistrés localement.

## Description longue proposée

La lumière tourne. La porte vous attend. Touchez au bon moment.

Luma Loop est un jeu de rythme visuel calme et immédiat. Suivez la luciole lumineuse autour du noyau, puis touchez l’écran lorsqu’elle traverse l’arc doré. Chaque réussite fait grandir votre élan; chaque erreur vous laisse une nouvelle chance de retrouver le rythme.

Le jeu privilégie des parties courtes, des réglages de confort pour le son, les vibrations et le contraste, ainsi qu’une progression locale sans compte. Il ne contient aucune publicité, aucun achat intégré et aucune collecte de profil dans sa version actuelle.

## Décision de publication avant ajout de publicité

La version actuelle peut être préparée comme une version **sans publicité**. Avant une version financée par publicité, le propriétaire doit choisir et déclarer le public cible réel, vérifier le SDK publicitaire, les pratiques de données, la politique de confidentialité et les règles de la catégorie de store retenue. La fiche ne doit jamais annoncer « sans publicité » si un SDK diffuse ensuite des annonces.
